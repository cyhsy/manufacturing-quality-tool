# Knowledge Corpus

本目录包含 30 张来源驱动知识卡和 19 份本轮合法公开取得的原始 PDF。原始文件按工序存放；焊接核心资料为 TWI 的公开 HTML 页面，因此只在来源清单和知识卡中保存链接/公开内容，没有伪造本地 PDF。

## 使用规则

1. 知识卡正文只能概括 YAML 中列出的来源。
2. 标准只有官方摘要/预览时，不扩写付费条款、数值限值或接受等级。
3. 工业资料用于“检查方向”，不自动升级为普遍因果定律。
4. 同名缺陷必须携带 `process`；例如铸造气孔和焊接气孔不能共用机理。
5. 原始 PDF 保留用于人工审查；第一版检索索引使用知识卡，避免把长文噪声直接混入。

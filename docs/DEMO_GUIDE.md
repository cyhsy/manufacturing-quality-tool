# 项目演示指南

## 项目展示目标

本项目用于展示一个面向制造质量场景的轻量级数据分析工具：把质量异常 Excel/CSV 记录上传后，快速完成字段检查、数据预览、缺陷统计、Pareto 分析、多维度问题定位、质量摘要、日期趋势与批次追溯，并导出 Excel 分析报告。

展示时重点说明：这个项目不是完整企业系统，而是一个能跑通真实工作流程的质量数据分析 MVP。

## 推荐展示方式

1. 在线演示链接

   优先使用已部署的 Streamlit 在线链接，让对方直接看到可操作页面。

2. README + 截图

   在无法现场操作时，使用 README 和关键截图展示项目功能、技术栈、使用流程和边界。

3. 本地备用演示

   提前在本机配置好环境，可通过 `run_app.bat` 或命令行启动应用，避免现场重新安装 Python 和依赖。

## 1 分钟演示流程

1. 打开在线演示页面或本地 Streamlit 页面。
2. 上传 `sample_data/defect_records_sample.xlsx`。
3. 展示字段检查通过和数据预览。
4. 快速展示缺陷类型统计、Pareto 图和多维度问题定位。
5. 展示质量分析摘要和 Excel 报告下载按钮。
6. 用一句话总结：项目把分散的质量异常记录转成可查看、可定位、可汇报的分析结果。

## 3 分钟演示流程

1. 说明项目背景：制造质量异常记录常以 Excel 形式存在，人工统计耗时，汇报材料整理重复。
2. 上传示例数据，说明字段要求和字段检查作用。
3. 展示数据预览，说明项目先保证输入数据结构可读。
4. 展示缺陷类型统计和 Pareto 图，说明如何快速识别主要缺陷。
5. 展示多维度问题定位，说明可以从零件、工序、供应商、责任部门等维度找问题来源。
6. 展示质量分析摘要，说明系统会把关键统计结果整理成可汇报文字。
7. 展示日期趋势与批次追溯，说明可以观察高风险日期和批次问题。
8. 下载 Excel 报告，说明结果可以带走、归档或用于沟通。

## 面试时如何解释

### 为什么做这个项目

制造和质量岗位经常面对 Excel 质量异常记录。单纯会写代码不够，项目希望贴近现场业务，把数据整理、统计、定位和汇报串成一个可演示流程。

### 用户是谁

目标用户包括质量工程师、制造工程师、生产现场质量管理人员，以及机械/制造相关实习岗位人员。

### 解决什么问题

解决质量异常记录分散、人工统计慢、主要问题来源不直观、报告整理重复的问题。

### 当前已实现什么

已实现 Excel/CSV 上传、字段检查、数据预览、缺陷类型统计、Pareto 图、多维度问题定位、质量分析摘要、Excel 报告导出、日期趋势与批次追溯。

### 项目边界是什么

当前项目是轻量级分析和演示工具，不替代完整 QMS/MES/PLM 系统，不接大模型 API，不做自动图纸识别，不替代质量工程师判断。真实企业数据需要根据字段、流程和规则进一步适配。

### Codex/AI 在项目中起什么作用

Codex/AI 主要用于辅助拆解任务、生成和迭代代码、补充测试、整理文档。项目仍通过人工确认需求、运行页面、检查结果和执行测试来验证，不表述为 AI 自动完成项目。

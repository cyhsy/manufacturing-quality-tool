# 部署与展示指南

## 推荐部署方式

推荐使用 GitHub + Streamlit Community Cloud：

1. 将项目代码推送到 GitHub 仓库。
2. 在 Streamlit Community Cloud 中连接该仓库。
3. 选择入口文件 `app.py`。
4. 部署完成后获取在线演示链接。

这种方式适合项目展示、面试作品集和远程沟通，对方无需安装 Python 即可查看应用。

## 为什么不建议让别人现场安装 Python

- 安装 Python、创建虚拟环境和安装依赖会占用演示时间。
- 不同电脑的 Python 版本、网络环境和权限设置可能不同。
- 现场排查环境问题会影响对项目本身的展示。
- 在线链接、截图和本地备用环境更稳定，也更适合短时间展示。

## 部署前检查清单

- `app.py` 存在。
- `requirements.txt` 存在。
- `sample_data/` 示例数据存在。
- `README.md` 已说明使用方法。
- 本地可通过 `python -m streamlit run app.py` 正常启动。
- 示例数据可正常上传并完成分析。

## 部署后的展示方式

- 在线链接：作为首选演示入口。
- GitHub 仓库：展示代码结构、提交记录、README 和测试说明。
- README 截图：用于无法打开在线页面时的备用说明。

## 注意事项

- 不上传真实企业敏感数据。
- 当前项目使用示例数据演示。
- 在线版本不接大模型 API，不涉及密钥。
- 如果后续加入密钥、数据库或企业数据，需要重新设计部署和数据安全方案。

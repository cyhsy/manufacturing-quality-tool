# 截图清单

建议提前准备以下截图，用于 README、简历作品集、面试讲解和现场备用展示。

## 应用页面截图

- 项目首页 / 上传区域
- 字段检查通过
- 缺陷类型统计
- Pareto 图
- 多维度问题定位
- 质量分析摘要
- 日期趋势与批次追溯
- Excel 报告下载按钮

## 报告与过程截图

- 导出的 Excel 报告 sheet 标签
- Git commit 记录或测试通过截图

## 截图建议

- 优先使用示例数据 `sample_data/defect_records_sample.xlsx`。
- 截图中不要包含真实企业敏感数据。
- 页面截图尽量包含标题、关键图表和核心结果。
- Excel 报告截图重点展示 sheet 结构和分析结果，不需要截完整数据明细。

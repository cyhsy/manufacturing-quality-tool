# 简历与面试说明

## 可放入简历的项目经历

制造质量数据分析与检验计划辅助工具：基于 Python、Streamlit、Pandas 和 Plotly 开发的轻量级质量异常记录分析工具，支持 Excel/CSV 上传、字段完整性检查、缺陷类型统计、Pareto 图、多维度问题定位、日期趋势与批次追溯，并可导出 Excel 分析报告。项目围绕制造质量场景设计，用于辅助识别主要缺陷、问题来源和高风险日期；开发过程中使用 Codex 辅助模块拆解、代码实现、测试补充和文档迭代，并通过人工运行和 pytest 进行验证。

## 面试时 60 秒讲法

这个项目是一个面向制造质量场景的轻量级数据分析工具。我把质量异常记录作为输入，支持上传 Excel 或 CSV，然后做字段检查、原始数据预览、缺陷类型统计和 Pareto 分析，帮助用户先找出主要缺陷类型。之后又增加了按零件、工序、供应商和严重等级的多维度定位，以及日期趋势和批次追溯，最后可以导出 Excel 分析报告。

它不是完整的 QMS 或 MES 系统，也不替代质量工程师判断，定位是把常见的质量异常统计和汇报流程做成一个可复用的小工具。开发中我使用 Python、Streamlit、Pandas、Plotly、OpenPyXL 和 Pytest，并使用 Codex 辅助拆分任务、实现功能和整理文档。

## 面试官可能追问的问题

### 1. 这个项目解决的核心问题是什么？

核心是减少质量异常记录的手工统计工作。它把 Excel 中分散的异常记录转换成缺陷统计、Pareto 图、多维度定位、趋势追溯和 Excel 报告，帮助用户更快找到主要问题来源。

### 2. 为什么选择 Streamlit？

Streamlit 适合快速搭建数据分析类工具，不需要复杂前端工程就能完成上传、表格、图表和下载功能。对于这个项目的展示目标和轻量级定位来说，开发效率比较合适。

### 3. Pareto 图在这个项目里有什么意义？

Pareto 图用于识别主要缺陷类型，帮助用户把注意力放在累计影响最大的缺陷上。它适合质量改善中常见的优先级判断场景。

### 4. 多维度问题定位具体看哪些维度？

当前主要看零件、工序、供应商和严重等级。通过这些维度可以初步判断问题集中在哪些零件、生产环节、外部来源或风险等级上。

### 5. 日期趋势与批次追溯有什么作用？

日期趋势可以观察异常是否集中在某些日期或时间段，批次追溯可以帮助用户从批次角度查看问题分布。当前实现是基础分析，后续可以结合真实生产流转数据继续增强。

### 6. 这个项目如何验证？

使用示例数据进行页面运行和人工检查，同时用 pytest 对部分数据处理逻辑做测试。功能完成后也通过本地 Streamlit 页面检查上传、图表、摘要和导出流程。

### 7. 如果接入真实企业数据，需要改什么？

需要先适配真实记录模板，包括字段名称、日期格式、缺陷分类、责任部门和供应商编码等规则。必要时还要补充数据清洗、权限控制和企业系统对接。

### 8. 这个项目和企业级质量系统有什么区别？

它是轻量级分析辅助工具，不是完整企业级系统。它不包含登录权限、数据库、流程审批、系统集成、MES/QMS/PLM 对接，也不覆盖完整质量管理闭环。

### 9. Codex 在项目中起了什么作用？

Codex 主要用于辅助模块拆解、代码实现、测试补充和文档迭代。关键功能通过人工运行、页面检查和 pytest 验证，不表述为 AI 自动完成项目。

## 项目边界说明

- 不接大模型 API
- 不做自动图纸识别
- 不做完整 QMS/MES/PLM 系统
- 不替代质量工程师判断
- 当前使用示例数据验证，真实企业数据需要进一步适配字段和规则

## Codex/AI 使用说明

开发过程中使用 Codex 辅助完成任务拆解、实现建议、测试补充和展示文档整理。项目使用 Git 保存阶段性版本，并通过人工运行、页面检查和 pytest 测试验证功能。对外介绍时应强调这是个人主导的工程实践项目，AI 作为辅助工具参与迭代，不夸大为企业级系统或 AI 自动生成项目。
